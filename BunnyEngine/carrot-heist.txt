Carrot Heist

Carrot Heist is a 2D top-down stealth game built on a custom C++ game engine (BunnyEngine). 
Players control two bunny recruits — Toast and Tofu — under the guidance of Master Whiskers, a legendary retired thief who runs an underground Bunny Heist Academy. 
The tutorial level tasks players with stealing carrots from a grandma's garden as their first training mission.

=====================================================================

Narrative

Master Whiskers is a legendary retired bunny thief who now runs the Bunny Heist Academy — an underground school for aspiring bunny robbers.
Toast and Tofu are his newest recruits. Their training begins with small targets before moving to bigger heists across future levels.
Level 1 — Tutorial: Steal 8 carrots from grandma's backyard garden. The grandma herself patrols the garden. Use the bushes to hide, coordinate both bunnies, and escape through the burrow.

=====================================================================


Engine Systems

Window + OpenGL 4.6 context (GLFW + glad)
ImGui editor with dockspace layout
Framebuffer — game renders inside viewport panel
Renderer2D — colored quads + sprite rendering
Shader system — vertex + fragment shaders
Texture loader — PNG via stb_image
SpriteSheet + UV frame system
Camera2D — pan, zoom, reset (MMB drag, scroll, R)
Entity + Scene system
IScene interface — GL/ImGui render split
SceneManager — register, switch, update, render
Input system — keyboard + mouse polling
AudioManager — FMOD BGM + SFX, volume sliders
EditorInteraction — click to select, Alt+drag to move
SceneSerializer — save/load entities to JSON
TilemapRenderer — loads .tmj, renders tile layers


=====================================================================

Game Systems

MainMenuScene — background + buttons (Play, Guide, Options, Quit)
GameScene — full gameplay scene
WASD movement
Bunny switching — 1 (Tofu) / 2 (Toast)
Camera follow — smooth lerp to active bunny
Collision system — tilemap collision layers
Carrot pickup + counter (8 carrots)
AbilitySystem — J/K/L with cooldowns per bunny
Guard AI — patrol waypoints (ping-pong), vision cone
Alert states — Patrol → Suspicious → Alerted → Searching
Hide system — per bunny, H to hide, guard loses target
Dialogue system — typewriter effect, multi-line, speaker name
NPC interaction — Master Whiskers quest dialogue
PauseMenu — ESC to pause, Resume/Guide/MainMenu (reusable prefab)
GuideBook — multi-page book, Carrot_Next/Prev navigation
Win condition — collect all carrots + talk to NPC + both bunnies escape
Lose condition — grandma catches a bunny
Audio — BGM per scene, SFX on collect

Deferred bugs

⚠️  Main menu background zooms in when returning from game scene
    → Framebuffer size mismatch between editor viewport and fullscreen
    → Attempted fix: resize framebuffer to window size in MainMenu
    → Still not working, deferred

⚠️  GuideBook prev button hover misalignment in MainMenu
    → Works correctly in GameScene/PauseMenu
    → Something about MainMenu's ImGui window context causes offset
    → Deferred

⚠️  Options button in MainMenu has no functionality yet
    → Placeholder only

⚠️  LNK4098 warning — MSVCRT lib conflict
    → Harmless warning, doesn't affect runtime
    → Fix: Project Properties → Linker → /NODEFAULTLIB:MSVCRT

===== PAUSE MENU ======
For every new level scene, just add these 3 lines to OnEnter(): 

PauseMenu::Get().Close();
PauseMenu::Get().SetOnResume([this]() { /* resume logic */ });
PauseMenu::Get().SetOnMainMenu([this]() {
    SceneManager::Get().SwitchTo("MainMenu");
});
